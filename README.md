# CIPHER

> Defensive Security Analysis Platform

CIPHER é uma plataforma de análise defensiva desenvolvida para ajudar utilizadores, estudantes e profissionais de cibersegurança a responder a perguntas como:

- Este link parece seguro?
- Este domínio apresenta sinais de risco?
- Este endereço de e-mail é confiável?

A plataforma analisa **URLs**, **domínios** e **endereços de e-mail** utilizando verificações técnicas e fontes públicas para fornecer uma avaliação de risco clara e objetiva.

---

## Funcionalidades

- 🔗 Análise de URLs
- 🌐 Verificação de domínios
- 📧 Análise de endereços de e-mail
- 🌍 Consulta de registos DNS
- 📊 Avaliação automática de risco
- 📋 Relatórios claros e fáceis de interpretar
- 💻 Interface moderna e responsiva

---

## Como funciona

O CIPHER recolhe indicadores técnicos e informações públicas relacionadas com o alvo analisado, processando esses dados para produzir uma avaliação de risco.

As análises podem incluir, conforme aplicável:

- Configuração DNS
- Certificados HTTPS
- Configuração de e-mail (SPF, DKIM e DMARC, quando disponíveis)
- Indicadores técnicos de segurança
- Outras verificações não intrusivas

---

## Objetivo

O CIPHER foi desenvolvido exclusivamente para **cibersegurança defensiva**, educação e análise preventiva.

A plataforma ajuda utilizadores a tomar decisões mais informadas antes de visitar websites, interagir com domínios ou confiar em endereços de e-mail.

---

## O que o CIPHER NÃO faz

O CIPHER não executa:

- exploração de vulnerabilidades;
- ataques contra sistemas;
- bypass de autenticação;
- acesso a informação privada;
- enumeração de dados confidenciais;
- qualquer atividade ofensiva contra terceiros.

Todas as análises são realizadas utilizando verificações técnicas e informações publicamente disponíveis.

## Aviso

Os resultados representam uma avaliação baseada nas verificações disponíveis no momento da análise.

Nenhuma ferramenta consegue garantir com 100% de certeza que um website, domínio ou endereço de e-mail seja seguro ou malicioso.
